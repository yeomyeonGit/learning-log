# 01. Iterator vs Generator

## 태그
`언어 내부 동작(코루틴)` `메모리 최적화(지연 평가)` `디자인 패턴(Iterator)`

## 요약

이터레이터 프로토콜(`__iter__`/`__next__`)을 직접 구현한 클래스, `yield`를 사용한 제너레이터, 즉시 계산하는 list 버전을 비교했다.

- **디자인 패턴 관점**: `ReverseIterator` 클래스는 GoF Iterator 패턴을 파이썬 프로토콜로 구현한 것이고, 제너레이터는 같은 패턴을 언어 문법 차원에서 제공하는 버전이다.
- **런타임 관점**: 제너레이터는 함수의 실행 상태(스택 프레임)를 `yield` 시점에 멈췄다가 재개하는 메커니즘 — 코루틴의 축소판이며, 이후 `async`/`await` 학습의 기반이 된다.
- **메모리 관점**: `tracemalloc`으로 측정한 결과, list 버전은 전체 데이터를 한 번에 메모리에 올리는 반면 제너레이터는 필요한 값만 그때그때 계산해 피크 메모리가 낮다.
